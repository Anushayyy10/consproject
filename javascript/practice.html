Variables & Data Types

In JavaScript, variables store data values. We can use let or const. The operator typeof tells us what type of data a variable holds.

Input Playground

Evaluated Types (`typeof`)

Value: "Alex" typeof: string
Value: 21 typeof: number
Value: true typeof: boolean
JS Equivalent: 
let name = "Alex"; // typeof string
let age = 21; // typeof number
let isStudent = true; // typeof boolean
